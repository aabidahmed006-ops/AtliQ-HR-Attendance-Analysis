# AtliQ HR Presence Insights Dashboard

![AtliQ HR Presence Insights Dashboard](AtliQ_HR_Presence_Insights_Dashboard%20-%20Screenshot.png)

## 📊 Project Overview

The **AtliQ HR Presence Insights Dashboard** is an interactive Power BI dashboard designed to analyze employee attendance and work patterns.

The dashboard provides an overview of employee **presence, work-from-home (WFH), sick leave, present days, and attendance status** across April, May, and June 2022.

The project focuses on transforming attendance data into meaningful HR insights through **Power Query, DAX, and interactive Power BI visualizations**.

---

## 🎯 Project Objective

The main objective of this project is to help HR teams understand:

- Overall employee presence
- Work-from-home trends
- Sick leave patterns
- Employee attendance performance
- Present days by employee
- Attendance patterns by day and month
- Employees requiring attention based on attendance status

## 📌 Key KPIs

The dashboard includes the following key performance indicators:

- **Total Employees**
- **Presence %**
- **WFH %**
- **Sick Leave %**
- **Working / Present Days**

These KPIs update interactively based on the selected month or employee.

---

## 📈 Dashboard Features

### 1. Top 10 Employees by Present Days

Displays the employees with the highest number of present days.

### 2. Presence % by Date

Shows the daily employee presence percentage and helps identify changes and fluctuations in attendance over time.

### 3. WFH % by Month

Provides a monthly comparison of work-from-home percentages for April, May, and June 2022.

### 4. Employee Attendance Details

Provides employee-level information including:

- Employee Name
- Presence %
- WFH %
- Sick Leave %
- Attendance Status

### 5. WFH % by Day of Week

Shows which days of the week have higher work-from-home percentages.

### 6. Sick Leave % by Day of Week

Highlights sick leave patterns across different days of the week.

### 7. Attendance Status

Employees are categorized based on attendance performance:

- 🟢 **Good**
- 🟠 **Average**
- 🔴 **Attention**

## 🔄 Data Preparation

The attendance data was originally provided in monthly Excel sheets.

The data preparation process included:

1. Importing attendance data from Excel.
2. Combining monthly attendance data.
3. Transforming the attendance structure using Power Query.
4. Converting date-related fields into appropriate formats.
5. Cleaning and organizing employee attendance records.
6. Creating calculated measures using DAX.
7. Building an interactive Power BI dashboard.

---

## 📐 DAX & Power BI
